# Users & Tasks API

پروژه‌ی فعالیت ۳ فصل ۳: طراحی قرارداد اولیه‌ی یک REST API برای مدیریت کاربران و وظایف.

## منابع (Resources)
- **Users**: id, name, email, passwordHash
- **Tasks**: id, title, description, status, userId

رابطه‌ی داده‌ها یک‌به‌چند است: هر کاربر می‌تواند چند وظیفه داشته باشد و هر وظیفه متعلق به یک کاربر است.

## قواعد کلی
- قالب تبادل داده: JSON
- پیشوند مسیرها: /api
- احراز هویت برای مسیرهای محافظت‌شده با Bearer Token انجام می‌شود.
- رمز عبور به‌صورت هش‌شده ذخیره می‌شود و هرگز در پاسخ API نمایش داده نمی‌شود.

## اجرا
این مخزن در حال حاضر مستندات طراحی API را شامل می‌شود و پیاده‌سازی سرور در محدوده‌ی فعالیت فعلی نیست.
